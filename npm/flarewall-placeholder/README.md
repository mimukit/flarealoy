# flarewall is now flarealoy

This package holds the `flarewall` name only. It has no code and no command.

flarewall was renamed to [flarealoy](https://www.npmjs.com/package/flarealoy) before its first release. The `flarewall` security commands are now `flarealoy security <command>`.

```sh
npm install -g flarealoy
```

Source and docs: <https://github.com/mimukit/flarealoy>
